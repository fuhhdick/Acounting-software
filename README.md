# 轻记账 · 部署与使用说明

一个纯前端的本地记账 PWA，免 Mac、免开发者账号、免费，可装到 iPhone 主屏幕长期使用。数据只存在你自己的手机里（LocalStorage），不上传任何服务器。

## 一、文件清单（发布到网站只需要这些）

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构 |
| `style.css` | 样式（含深色模式） |
| `app.js` | 全部逻辑 |
| `manifest.webmanifest` | PWA 配置 |
| `sw.js` | 离线缓存（Service Worker） |
| `icons/` | App 图标（4 个 PNG） |

> `tools/` 文件夹是开发用的脚本，**不需要上传**。`.mnemon` 等隐藏目录也不要上传。

## 二、免费部署到 GitHub Pages（推荐，约 5 分钟）

1. 注册 GitHub 账号（免费）→ https://github.com/signup
2. 右上角 **+** → **New repository**，仓库名用英文，例如 `qingjizhang`，选 **Public**，点 **Create repository**。
3. 在仓库页面点 **uploading an existing file**，把上面表格里的 6 个文件/文件夹**整个拖进去**（`icons` 文件夹一起拖），提交时写一句说明，点 **Commit changes**。
4. 进仓库 **Settings** → 左侧 **Pages** → **Source** 选 `Deploy from a branch`，**Branch** 选 `main`、目录 `/ (root)` → **Save**。
5. 等 1~2 分钟，页面顶部会显示网址：`https://你的用户名.github.io/qingjizhang/`
6. 用手机 Safari 打开这个网址测试。

> 网址打不开？确认仓库是 **Public**，且 Pages 里显示 “Your site is live at …”。

## 三、装到 iPhone 主屏幕（变成 App）

1. 用 **Safari** 打开你的网址（这一步必须用 Safari）。
2. 点底部中间的**分享按钮**（方框 + 上箭头图标）。
3. 找到并点击 **「添加到主屏幕」**。
4. 点右上角 **「添加」**。
5. 回到桌面，会看到一个绿色图标 **「轻记账」**，点它全屏打开，和原生 App 几乎一样。

> 想离线也能用、列表更完整，建议第一次打开后**再正常用一次**（让 Safari 缓存好文件）。

## 四、日常使用提示

- **总资产 / 已有存款**：在「设置 → 我的账户」点账户右侧 ✎，填「初始余额」（开始记账前该账户已有的钱，信用卡欠款可填负数）。之后首页顶部和「统计 → 总览」会显示**总资产**，并随每笔记账自动增减。
- **统计中心**：「统计」页顶部可切换 **总览 / 月度 / 每日 / 年度 / 账户** 五个子页——每日流水图、每年流水图与历年对比、按支付方式（账户）的收支占比、以及汇总账目分析（结余率、日均支出、最大支出分类等）。
- **数据备份**：设置 →「导出完整备份」得到 `.json` 文件存好；换手机或清数据后，用「导入备份」恢复。**卸载 App / 清除 Safari 数据会永久丢失数据，请先备份。**
- **CSV 导出**：可发给电脑用 Excel 打开。
- **深色模式**：设置 →「外观」，可选自动/浅色/深色。

## 五、更新网站（改版后如何让手机看到新版）

1. 按第二步同样的方法重新上传覆盖文件。
2. 打开 `sw.js`，把 `const CACHE = 'qingbook-v1'` 里的 `v1` 改成 `v2`（每次更新 +1）。
3. 手机 Safari 重新打开网址一次，之后从主屏图标打开即是新版。

## 六、想在本机先预览？

因为 PWA 需要 HTTPS 才能完整离线，最简单还是直接部署到 GitHub Pages。若只想本机瞄一眼，可在装了 Python 的电脑上，在本文件夹运行：

```bash
python -m http.server 8000
```

然后浏览器打开 `http://127.0.0.1:8000`（此方式只能用浏览器打开，不能“添加到主屏幕”）。
